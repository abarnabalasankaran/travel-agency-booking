🌍 TravelDreamscape
A responsive and interactive travel booking web app that allows users to explore destinations, book trips, and leave reviews—all built using React, TypeScript, and localStorage-based mock APIs.

✨ Features
🔍 Explore Destinations – Browse through a curated list of travel destinations with descriptions and images.

🧳 Booking System – Create and manage bookings with customizable travel dates.

🧑‍💼 User Authentication – Mock login/logout functionality with session tracking.

📝 Reviews – Leave and read reviews for destinations.

🗃️ LocalStorage as Mock Backend – No backend server needed. All data is persisted using browser localStorage.

🕒 Mock API Simulation – Simulated API with artificial delay to mimic real-world latency.

🛠️ Tech Stack
Frontend: React + TypeScript

Styling: Tailwind CSS / CSS Modules (customizable)

Data Handling: LocalStorage

Routing: React Router

State Management: React Context / useState
